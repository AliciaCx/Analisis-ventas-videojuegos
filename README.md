
# Análisis de Ventas de Videojuegos

## Descripción

Este proyecto consiste en realizar un análisis de las ventas de videojuegos mediante el lenguaje de programación R, utilizando diferentes conjuntos de datos que contienen información sobre videojuegos, plataformas, géneros y regiones.

Primero comenzaremos con la preparación y el tratamiento de los datos, seguido de un análisis exploratorio que permite estudiar la evolución de las ventas y comparar el comportamiento comercial de los videojuegos según diferentes características.

Además, se desarrolla un dashboard interactivo que facilita la exploración de la información mediante filtros, tablas y representaciones gráficas.

## Objetivos

- Preparar, limpiar y transformar conjuntos de datos.
- Analizar las ventas de videojuegos según plataformas y géneros.
- Comparar las ventas en diferentes regiones geográficas.
- Identificar tendencias y patrones en los datos.
- Desarrollar visualizaciones para facilitar la interpretación de los resultados.
- Crear un dashboard interactivo para explorar la información.

## Desarrollo del proyecto

1. **Preparación y tratamiento de los datos**
   - Importación de los conjuntos de datos.
   - Limpieza y transformación de la información.
   - Preparación de las variables para el análisis.

2. **Análisis exploratorio de datos**
   - Estudio de las ventas globales y regionales.
   - Comparación de plataformas y géneros.
   - Análisis de la evolución de las ventas a lo largo del tiempo.

3. **Visualización de datos**
   - Elaboración de gráficos y representaciones interactivas.
   - Creación de tablas para consultar la información.
   - Visualización de datos por regiones y categorías.

4. **Desarrollo del dashboard**
   - Integración de las visualizaciones.
   - Incorporación de filtros interactivos.
   - Presentación de la información en un panel de análisis.

## Resultados

El análisis permitió identificar diferencias en las ventas de videojuegos según las plataformas, los géneros y las regiones geográficas.

Se desarrollaron distintas visualizaciones para facilitar la interpretación de los datos y observar patrones en el comportamiento comercial de los videojuegos.

Finalmente, se creó un dashboard interactivo que integra gráficos, tablas y filtros, permitiendo explorar la información de forma dinámica y consultar los resultados desde diferentes perspectivas.

## Cómo consultar el proyecto

Los archivos de código y el dashboard pueden consultarse desde GitHub.

Para ejecutar el proyecto será necesario instalar R y los paquetes utilizados en el análisis, así como disponer de los conjuntos de datos correspondientes.
